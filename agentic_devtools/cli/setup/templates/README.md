# Workflow Templates

These files are starter [LangGraph](https://langchain-ai.github.io/langgraph/)
workflow definitions generated by `agdt-setup`.

## What's included

- **work-on-issue.py** — A runnable workflow graph that processes an issue
  through planning, implementation, verification, and commit stages.
- **review-pr.py** — A skeleton workflow for reviewing a pull request.
  Uncomment the node functions and fill in the `# TODO` sections.

## How to customise

1. Copy the template you want to modify.
2. Edit the node functions to call your own tools (Jira, Git, CI, etc.).
3. Adjust the graph edges to match your team's process.
4. Optionally add a LangGraph checkpointer for durable state.

## Running a template

```bash
python work-on-issue.py
```

For more information see the
[LangGraph documentation](https://langchain-ai.github.io/langgraph/).
