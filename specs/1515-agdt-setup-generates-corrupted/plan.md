## Research Summary

Key choice: a single `normalize_pem_block(pem: str) -> str` function in `cert_utils.py` that strips blank/whitespace-only lines and
trims each content line, applied at both extraction and bundle-write time.

## Design Overview

```text
openssl s_client output
        │
        ▼
fetch_certificate_chain_openssl()
        │ re.findall(cert_pattern, ...)
        ▼
  normalize_pem_block()  ← NEW (applied to each extracted block)
        │
        ▼
  return normalized chain
        │
        ▼
_build_unified_ca_bundle()
        │ re.findall on per-host PEMs
        │ normalize_pem_block() ← NEW (applied to each extracted block)
        ▼
  write unified-ca-bundle.pem (newline='\n')
```

The fix is surgical: add one shared function and call it in two existing locations.

## Implementation Phases

### Phase 1: Add `normalize_pem_block` function

**File**: `agentic_devtools/cli/cert_utils.py`

**Deliverable**: New function with signature:

```python
def normalize_pem_block(pem: str) -> str:
```

**Logic**:

1. Split input on `\n` (after replacing `\r\n` → `\n`)
2. Emit `-----BEGIN CERTIFICATE-----` (canonical, trimmed)
3. For lines between markers: strip whitespace, skip empty lines
4. Emit `-----END CERTIFICATE-----` (canonical, trimmed)
5. Join with `\n`, append trailing `\n`

**Idempotency**: A well-formed PEM block must produce byte-for-byte identical output.

### Phase 2: Integrate into `fetch_certificate_chain_openssl`

**File**: `agentic_devtools/cli/cert_utils.py`

**Change**: After `re.findall(cert_pattern, output, re.DOTALL)`, apply `normalize_pem_block` to each match before joining:

```python
certs = [normalize_pem_block(c) for c in re.findall(cert_pattern, output, re.DOTALL)]
```

### Phase 3: Integrate into `_build_unified_ca_bundle`

**File**: `agentic_devtools/cli/setup/commands.py`

**Changes**:

1. Import `normalize_pem_block` from `cert_utils`
2. Normalize each cert extracted from per-host PEMs before de-duplication
3. Open the output file with `newline='\n'` to ensure Unix line endings on all platforms


Note: `Path.write_text` supports `newline` parameter since Python 3.10. If older support needed, use `open(... newline='\n')`.
