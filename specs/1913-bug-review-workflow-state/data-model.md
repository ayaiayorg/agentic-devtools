# Data Model: PR Review Workflow State Directory Mismatch

**Issue**: #1913 | **Branch**: `speckit/1913/phase-3-plan` | **Spec**: [spec.md](spec.md)

## 1. Pin File Schema

The `pinned-state-dir.json` file is written to `{git_root}/.agdt/pinned-state-dir.json`.

```json
{
  "state_dir": "/absolute/path/to/state/dir",
  "workflow": "pull-request-review",
  "created_utc": "2026-06-07T00:00:00+00:00",
  "ttl_hours": 24
}
```

| Field | Type | Description |
|-------|------|-------------|
| `state_dir` | `str` (absolute path) | Canonical resolved state directory for this workflow run |
| `workflow` | `str` | Workflow name; must be a member of `RECOGNIZED_PIN_WORKFLOWS` |
| `created_utc` | `str` (ISO 8601) | UTC timestamp used for TTL validation |
| `ttl_hours` | `int` | Pin lifetime in hours used for expiry validation |

**TTL**: Default 24 hours (`DEFAULT_PIN_TTL_HOURS`). Pins older than TTL are treated as absent by `read_and_validate_pin_file()`.

**Atomic write**: `os.replace()` ensures no partial reads.

## 2. State Directory Resolution Priority

`get_state_dir()` resolution order (highest to lowest priority):

| Priority | Source | Notes |
|----------|--------|-------|
| 1 | `AGENTIC_DEVTOOLS_STATE_DIR` env var | Set by auto-execute subprocess; cleared by `copilot_auto_start_cmd` |
| 2 | `.agdt/pinned-state-dir.json` (validated) | **New for this fix**: written to target worktree by `_run_auto_execute_command` |
| 3 | `runtime-bootstrap.json` | May reference source repo root — root cause of mismatch |
| 4 | `_unscoped` fallback | Generic fallback |
| 5 | `.agdt-temp` fallback | Temporary fallback |
